# 指數・對數卡片挑戰

高中數學三人觸控遊戲。左、中、右三區可各自開始、計時、作答與結算。

您附圖中的 GitHub Pages 專案網址為：`https://whalytw.github.io/1ch2-exponent-log-card-game/`

## 此版設定

- 預設題數：簡單 6 題、中等 4 題、困難 0 題。
- 三種難度各有 8 張候選卡片（教師可各自設為 8～24 張）；每題預設時間依序為 30、45、60 秒。
- 每個區域開始前可從下拉選單選座號，也可選「不選座號」。教師可設定座號起訖範圍，預設 1～30 號，允許 1～99 號的範圍。選過座號的學生在結算時會看到座號與總分。
- 指數題只使用整數次方；遊戲區的觸控長按不會開啟頁面右鍵選單。

## 更新 GitHub Pages

解壓後，將 `index.html`、`style.css`、`game.js` 覆蓋現有 GitHub 專案**根目錄**的同名檔案。`README.md` 是說明文件，亦可一併上傳。請上傳解壓後的檔案，不要只上傳 ZIP，也不要多包一層 `dist` 資料夾。

重新整理網站後，點頁面右上角「全螢幕」。按鈕顯示「離開全螢幕」時，才是網頁本身進入全螢幕。

更新時，若先前題數仍是原本的 4／4／2 預設，會轉為 6／4／0；曾自行修改的題數會保留。此遊戲沒有後端或 Firebase 依賴；教師設定只儲存在目前瀏覽器。也可以直接開啟 `index.html` 在電腦上試玩。
