# 指數・對數卡片挑戰

建議 GitHub 專案名稱：`exponent-log-card-arena`

高中數學三人觸控遊戲。左、中、右三區可各自開始、計時、作答與結算。教師可設定指數及／或常用對數題型、簡中難題數及每題秒數。設定只儲存在目前瀏覽器；遊戲不需要 Firebase 或其他後端。

## 檔案

- `index.html`：遊戲頁面
- `style.css`：介面與觸控版面
- `game.js`：出題、判分、計時與設定

## 放到 GitHub Pages

建立 `exponent-log-card-arena` 專案後，把壓縮檔**解壓**，將上面三個網站檔案放在專案根目錄（與本 README 同一層），再啟用該專案的 GitHub Pages。不要只上傳 ZIP 本身，也不要額外包一層 `dist` 資料夾。頁面使用相對路徑，因此可放在 GitHub Pages 的專案網址下。

若 GitHub 使用者名稱是 `whalytw`，啟用後的預期網址為 `https://whalytw.github.io/exponent-log-card-arena/`。此網址在您建立並發布專案前不會生效。

也可以直接開啟 `index.html` 在目前電腦上試玩。
