# 指數・對數卡片挑戰

高中數學三人觸控遊戲。左、中、右三區可各自開始、計時、作答與結算。

目前您附圖中的 GitHub Pages 專案網址為：`https://whalytw.github.io/1ch2-exponent-log-card-game/`

## 此版修改

- 遊戲區攔截觸控長按造成的瀏覽器右鍵選單，並避免文字選取；右上角全螢幕按鈕會顯示進出狀態。
- 簡單、中等、困難的候選卡片預設均為 8 張（各自可設 8～24 張）。
- 每題預設秒數依序為 30、45、60 秒。
- 所有指數題的題目與候選卡片均使用整數次方。
- 卡片區依螢幕高度縮放，鎖定答案按鈕保留在遊戲區內。
